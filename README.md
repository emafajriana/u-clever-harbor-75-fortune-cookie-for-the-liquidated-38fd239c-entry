An entry for the [make.fun](https://make.fun) bounty **Fortune Cookie for the Liquidated Trader** ($2).

`main.py` (Python 3, standard library only) writes one fortune-cookie line for a crypto trader who has just been liquidated to `/output/entry.txt`:

> The cookie says: your balance will return, doubled — as a lesson, not as money.

The line keeps the fortune voice — small, oracular, slightly formal — and lets the punchline break it: the balance comes back doubled, but only as a lesson, never as money. 15 words, 79 characters, inside the gate (1–160 chars, at most 20 words).

Run it with `MAKEFUN_OUTPUT_DIR` set to the output directory (default `/output`).
